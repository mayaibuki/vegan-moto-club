# Category rules

How a product is assigned a Notion Category. Apply the rules in order.

- Rule 1: Has armor, armor pockets or a CE garment class (EN 17092)? File by garment: upper body = Jackets (includes armored hoodies, overshirts and riding sweaters), legs = Pants, one-piece = Racing Suits.
- Rule 2: Standalone armor, airbags and armored base layers = Protection. Armored leggings may carry Pants + Protection.
- Rule 3: Gloves and glove liners = Gloves. Footwear = Boots.
- Rule 4: Insulating mid-layer jackets and pants = Jackets / Pants (owner decision 2026-11-14).
- Rule 5: Everything else = Other, and only Other (no second category): rain over-garments without armor (jackets, pants, suits), unarmored base layers and undersuits, thermal base layers, non-protective tees and casual clothing including unarmored jeans, helmets, luggage and bags, accessories.

## Notes

- Sentence one of a description names the product type ("tank bag", "rain jacket"), never the word "Other".
- Luggage, helmets and accessories: Gender Unisex, Level of Protection "Not protective", all three seasons unless the page says otherwise.
- Never create Notion options.
- "Street wear" was retired on 2026-11-14.
